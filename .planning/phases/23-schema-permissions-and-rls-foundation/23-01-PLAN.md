**MessageAttachment**: id, organizationId, messageId (with Message relation + onDelete: Cascade), fileName (String), fileSize (Int), mimeType (String), storageUrl (String), createdAt (@default(now())). NO deletedAt. Constraints: @@index([organizationId]), @@index([messageId]).

**MessageMention**: id, organizationId, messageId (with Message relation + onDelete: Cascade), mentionedUserId (String?), mentionType (String), teamId (String?), createdAt (@default(now())). NO deletedAt. Constraints: @@index([organizationId]), @@index([messageId]).

**NotificationPreference**: id, organizationId, userId (with User relation), channelId (String?), channel (Channel? @relation), level (String @default("all")), emailDigest (Boolean @default(true)), createdAt (@default(now())), updatedAt (@updatedAt). NO deletedAt. Constraints: @@unique([userId, channelId]), @@index([organizationId]).

**PushSubscription**: id, organizationId, userId (with User relation), endpoint (String), p256dh (String), auth (String), createdAt (@default(now())). NO deletedAt. Constraints: @@unique([userId, endpoint]), @@index([organizationId]).
