**useMessagingNotifications.ts** per D-06:

```typescript
'use client'
export function useMessagingNotifications(orgId: string, userId: string): void
```

This hook:
1. Gets the Supabase client from useRealtime()
2. Subscribes to Realtime broadcast topic `notif:{orgId}:{userId}` on mount
3. On receiving a broadcast event with type "messaging_mention" or "messaging_dm", shows a MessagingToast
4. Uses useState to track current toast; auto-dismiss after 5 seconds
5. Invalidates the channels query key to refresh unread counts: `queryClient.invalidateQueries({ queryKey: ['channels'] })`
6. Cleans up subscription on unmount

The hook should be called once in the messaging page layout, NOT per-channel.

Also add a focus/visibility listener per the CONTEXT.md specifics ("mark-as-read should fire on channel focus, not just click"):
```typescript
useEffect(() => {
  if (!channelId) return
  const handleFocus = () => {
    fetch(`/api/messaging/channels/${channelId}/read`, { method: 'PATCH' }).catch(() => {})
  }
  document.addEventListener('visibilitychange', () => {
    if (document.visibilityState === 'visible') handleFocus()
  })
  return () => document.removeEventListener('visibilitychange', handleFocus)
}, [channelId])
```

**usePushSubscription.ts** per D-09:

```typescript
'use client'
export function usePushSubscription(): {
  isSupported: boolean
  isSubscribed: boolean
  subscribe: () => Promise<void>
  unsubscribe: () => Promise<void>
}
```

Implementation:
1. Check if `'serviceWorker' in navigator && 'PushManager' in window` — set isSupported
2. On mount, check if a push subscription exists: `navigator.serviceWorker.ready.then(reg => reg.pushManager.getSubscription())`
3. `subscribe()`:
   a. Request notification permission via `Notification.requestPermission()`
   b. If granted, subscribe: `reg.pushManager.subscribe({ userVisibleOnly: true, applicationServerKey: urlBase64ToUint8Array(process.env.NEXT_PUBLIC_VAPID_PUBLIC_KEY!) })`
   c. Send subscription to server: POST `/api/messaging/push-subscription` with `{ endpoint, keys: { p256dh, auth } }`
4. `unsubscribe()`:
   a. Get existing subscription, call `.unsubscribe()`
   b. DELETE `/api/messaging/push-subscription` with `{ endpoint }`

Include the `urlBase64ToUint8Array` helper function inline (standard Web Push utility — converts base64-encoded VAPID key to Uint8Array).

**Wire push prompt into messaging page:** The hook should be called in the messaging page layout. On first visit where isSupported && !isSubscribed, show a subtle banner: "Enable push notifications to get notified of new messages when you're away." with "Enable" and "Not now" buttons. "Not now" dismisses for the session (localStorage flag). "Enable" calls subscribe().
