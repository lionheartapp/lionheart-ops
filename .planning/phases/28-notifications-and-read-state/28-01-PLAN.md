Create src/lib/services/messagingNotificationService.ts per D-04 and D-05.

This service creates Notification rows for messaging events. Two exported functions:

**notifyMentionedUsers(messageId: string, channelId: string, authorId: string, authorName: string):**
1. Query MessageMention rows for this messageId where type = "user" and userId is not null and userId !== authorId (don't notify yourself)
2. For each mentioned user, check MessagingNotificationPreference for this channel — skip if level = "none"
3. Call createBulkNotifications with type "messaging_mention", title "{authorName} mentioned you in #{channelName}", linkUrl "/messaging?channel={channelId}", body = first 100 chars of message content
4. Use rawPrisma for the mention + preference queries (this runs inside sendMessage which is already in org context, but the notification service uses rawPrisma internally)

**notifyDMRecipients(channelId: string, authorId: string, authorName: string, contentPreview: string):**
1. Query ChannelMember rows for this channel where userId !== authorId
2. For each recipient, check MessagingNotificationPreference — skip if level = "none"
3. Call createBulkNotifications with type "messaging_dm", title "New message from {authorName}", linkUrl "/messaging?channel={channelId}", body = first 100 chars of contentPreview

Add "messaging_mention" and "messaging_dm" to the NotificationType union in notificationService.ts and to the NOTIFICATION_TYPES array.
