    **useMessageSearch.ts** — TanStack Query hook (per D-10):
    - `useMessageSearch(query: string, channelId?: string)`: Uses `useInfiniteQuery` to GET `/api/messaging/search?q={query}&limit=20&cursor={cursor}`.
    - Enabled only when `query.trim().length >= 2` (minimum 2 chars to search).
    - Debounce the query: use a 300ms debounce on the query string before triggering the fetch. Use the `useDebounce` pattern from the codebase (or implement inline if not available).
    - Query key: `['message-search', query, channelId]`.
    - Returns `{ results: SearchResult[], hasMore, fetchNextPage, isLoading, isFetchingNextPage }`.

    **SearchPanel.tsx** — Overlay panel (per D-09):
    - Renders as a centered modal overlay (similar to Cmd+K pattern in apps like Linear or Slack).
    - Fixed position, full-screen backdrop with `bg-black/30`, centered panel `max-w-lg w-full max-h-[70vh]`.
    - Panel has:
      1. Search input at top (auto-focused, using SearchInput component from `src/components/ui/` or INPUT_CLASSES).
      2. Results list below, scrollable.
      3. Each result shows: channel name (badge), author avatar + name, message content (truncated to ~120 chars), relative date.
      4. Clicking a result calls `onNavigate(channelId)` and closes the panel.
      5. "Load more" button at bottom when hasMore is true.
    - Close on Escape, close on click-outside, close on result selection.
    - Empty state: "Search messages across your channels" when no query.
    - No results state: "No messages found for '{query}'" when query has no results.
    - Loading state: skeleton rows while fetching.
    - Props: `onClose: () => void`, `onNavigate: (channelId: string) => void`.
