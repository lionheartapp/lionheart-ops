**Service functions:**

1. `createChannel(input: z.infer<typeof CreateChannelSchema>, userId: string)` -- Per D-04, auto-add creator as ChannelMember with role='owner'. Generate slug from name via toSlug(). If slug collision within org, append a random 4-char suffix. Use `prisma.channel.create({ data: { name, slug, type, description, createdById: userId }, include: { members: { include: { user: { select: { id, firstName, lastName, avatar } } } } } })` then create ChannelMember in same call or sequential await.

2. `getChannels(userId: string)` -- Return all channels the user can see: all PUBLIC channels (not archived), PRIVATE channels where user is a member, DM/GROUP_DM channels where user is a member. Use `prisma.channel.findMany` with OR conditions. Include member count and last message preview (latest message's content + authorId + createdAt). Order by most recent message activity.

3. `getChannel(channelId: string, userId: string)` -- Fetch single channel with members. For PRIVATE/DM/GROUP_DM, verify user is a member (throw 'Channel not found' if not). Include members with user select { id, firstName, lastName, avatar, email }.

4. `updateChannel(channelId: string, userId: string, input: z.infer<typeof UpdateChannelSchema>)` -- Verify user is channel owner/admin OR has MESSAGING_CHANNELS_MANAGE permission. If name changed, regenerate slug. Update via `prisma.channel.update`.

5. `archiveChannel(channelId: string, userId: string)` -- Set archivedAt = new Date(). Verify user is owner or has MESSAGING_CHANNELS_MANAGE. DM/GROUP_DM channels cannot be archived (throw error).

6. `getChannelMembers(channelId: string)` -- Return all ChannelMember rows with user include { id, firstName, lastName, avatar, email }. Order by role (owner first, then admin, then member), then by createdAt.

7. `addMember(channelId: string, input: z.infer<typeof AddMemberSchema>, actingUserId: string)` -- Verify acting user is channel owner/admin or has MESSAGING_CHANNELS_MANAGE. Upsert ChannelMember with channelId_userId compound key. Cannot add to DM channels (throw error). Return the new member with user include.

8. `removeMember(channelId: string, userId: string, actingUserId: string)` -- Verify acting user is channel owner/admin or has MESSAGING_CHANNELS_MANAGE. Cannot remove self if sole owner (throw error). Hard-delete the ChannelMember row (ChannelMember uses hard delete per Phase 23 decision). Cannot remove from DM channels (throw error).

9. `findOrCreateDM(callerUserId: string, targetUserIds: string[])` -- Per D-05 and D-06. Combine callerUserId + targetUserIds, sort, deduplicate. If 1 target user -> type=DM. If 2-7 target users -> type=GROUP_DM. Check if a channel of that type already exists with EXACTLY those members (query ChannelMember grouped by channelId, match on count + all userIds present). If found, return it. Otherwise create new Channel + ChannelMember rows for all participants (all with role='member', caller with role='owner'). Max 8 total (caller + 7) per D-06.

**Implementation:**

```typescript
// ─── Messaging Feature Gate (D-02) ──────────────────────────────
if (pathname.startsWith('/api/messaging/')) {
  const orgId = requestHeaders.get('x-org-id')
  if (orgId) {
    const { rawPrisma } = await import('@/lib/db')
    const org = await rawPrisma.organization.findUnique({
      where: { id: orgId },
      select: { messagingEnabled: true },
    })
    if (!org?.messagingEnabled) {
      return NextResponse.json(
        { ok: false, error: { code: 'FEATURE_DISABLED', message: 'Messaging is not enabled for this organization' } },
        { status: 403 }
      )
    }
  }
}
```
