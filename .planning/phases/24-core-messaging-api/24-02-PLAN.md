   - Per D-09: only the author can edit. Fetch message, check `authorId === userId`, throw 'You can only edit your own messages' if not.
   - Update content and set `editedAt: new Date()`
   - Re-run `parseMentions` (delete old mentions for this messageId, create new ones)
   - Return shaped updated message

3. `deleteMessage(messageId: string, userId: string, canDeleteAny: boolean)`:
   - Per D-08: author can always soft-delete own messages. If `authorId !== userId`, check `canDeleteAny` (passed from route handler which checks MESSAGING_MESSAGES_DELETE_ANY).
   - Soft-delete via `prisma.message.update({ where: { id: messageId }, data: { deletedAt: new Date() } })`
   - If message had a parentId, decrement parent's replyCount
   - Return `{ deleted: true }`

4. `parseMentions(content: string, messageId: string)`:
   - Per D-07: server-side mention parsing on send.
   - Delete existing MessageMention rows for this messageId (idempotent for edit re-parse)
   - Regex patterns:
     - `@user:([a-zA-Z0-9]+)` or `<@([a-zA-Z0-9]+)>` -> mentionType='user', mentionedUserId=captured ID
     - `@channel` -> mentionType='channel'
     - `@here` -> mentionType='here'
     - `@team:([a-zA-Z0-9]+)` -> mentionType='team', teamId=captured ID
   - Create MessageMention rows via `prisma.messageMention.createMany`
   - Note: The exact mention syntax format will be refined when the UI composer is built in Phase 26. For now, support both `<@userId>` (Slack-like) and `@user:userId` formats.

**1. `getMessages(channelId: string, userId: string, opts: { before?: string; after?: string; limit: number })`**

Per D-10: cursor-based pagination with before/after.

```typescript
export async function getMessages(
  channelId: string,
  userId: string,
  opts: { before?: string; after?: string; limit: number }
): Promise<{ messages: MessageWithAuthor[]; hasMore: boolean; cursor: string | null }> {
  const db = prisma as unknown as OrgPrismaClient

  // 1. Verify user is member of channel
  const membership = await db.channelMember.findUnique({
    where: { channelId_userId: { channelId, userId } },
  })
  if (!membership) throw new Error('Not a member of this channel')

  // 2. Build cursor condition
  let cursorCondition = {}
  if (opts.before) {
    const cursorMsg = await db.message.findUnique({ where: { id: opts.before }, select: { createdAt: true } })
    if (cursorMsg) cursorCondition = { createdAt: { lt: cursorMsg.createdAt } }
  } else if (opts.after) {
    const cursorMsg = await db.message.findUnique({ where: { id: opts.after }, select: { createdAt: true } })
    if (cursorMsg) cursorCondition = { createdAt: { gt: cursorMsg.createdAt } }
  }

  // 3. Query with +1 for hasMore detection
  const messages = await db.message.findMany({
    where: { channelId, deletedAt: null, ...cursorCondition },
    orderBy: { createdAt: opts.before ? 'desc' : 'asc' },
    take: opts.limit + 1,
    include: {
      author: { select: { id: true, firstName: true, lastName: true, avatar: true } },
    },
  })

  const hasMore = messages.length > opts.limit
  if (hasMore) messages.pop()
  if (opts.before) messages.reverse()  // Restore chronological order

  return {
    messages: messages.map(m => shapeMessage(m as unknown as Record<string, unknown>)),
    hasMore,
    cursor: messages.at(-1)?.id ?? null,
  }
}
```

SELECT m.id, m."channelId", c.name as "channelName",
       m."authorId", u."firstName", u."lastName", u.avatar,
       m.content, m."createdAt"
FROM "Message" m
JOIN "Channel" c ON c.id = m."channelId"

LIMIT ${limit + 1}
